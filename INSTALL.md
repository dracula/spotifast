### [Spotifast](https://spotifast.rocks)

#### Install using Git

If you are a Git user, you can install the theme and keep it up to date by cloning the repo:

```bash
git clone https://github.com/dracula/spotifast.git
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/dracula/spotifast/archive/main.zip) option and unzip it.

#### Activating theme

1. Open Spotifast and go to `Settings > Appearance > Theme`;
2. Click the **Open themes folder** button beside the theme picker;
3. Copy `Dracula.json` into that folder;
4. On macOS or Windows, run `spotifast reload-themes` (or restart the app). Linux picks up the file on its own;
5. Pick **Dracula** from the theme picker.

> Spotifast tints pages with the current album art by default. Turn off **Colour from album art** if you want Dracula purple everywhere.
